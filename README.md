# ✦ RESONANCE — תדרים לאיזון הגוף והנשמה

אפליקציית פרימיום בסגנון Tidal להאזנה לתדרי ריפוי: **סולפג'יו, צ'אקרות, גלי מוח,
Binaural Beats, תיקון DNA ותדרי כדור הארץ** — עם מנוע סינתזה חי ומנדלה ויזואלית
שמגיבה לצליל בזמן אמת.

## ✨ מה מיוחד כאן

- **סאונד באיכות הגבוהה ביותר האפשרית** — כל יצירה מסונתזת בזמן אמת ב-Web Audio API
  בדיוק של אלפית הרץ. אין קבצי MP3, אין דחיסה, אין אובדן. שכבות הרמוניות
  ("קערה טיבטית"), LFO נשימה, ריוורב קתדרלה גנרטיבי ורעש ורוד אטמוספרי.
- **46 יצירות תדר** מסווגות ב-9 קטגוריות: סולפג'יו (9 התדרים), 7 הצ'אקרות,
  גלי מוח (דלתא→גמא 40Hz), שינה, ריכוז, תיקון DNA, תדרי כדור הארץ, מדיטציה, אנרגיה.
- **שלושה מצבי סינתזה** — תדר טהור · Binaural (🎧) · איזוכרוני (גם ברמקולים).
- **ויזואליזציית מנדלה חיה** — Canvas ברזולוציית הפיקסלים הנטיבית של המסך
  (Retina/4K/8K), מוזנת מ-AnalyserNode ונצבעת בפלטת היצירה.
- **PWA מלאה** — התקנה על מסך הבית, עבודה אופליין, Media Session במסך הנעילה.
- **טיימר שינה** עם fade-out עדין של 10 שניות · מועדפים · אחרונים · חיפוש ·
  Auto-Save ל-localStorage.
- **עברית RTL** בעיצוב כהה יוקרתי: שחור עמוק, גרדיאנט זהב-סגול, טיפוגרפיית Heebo.

## 🚀 הרצה

אפליקציה סטטית ללא build וללא תלויות:

```bash
python3 -m http.server 8000
# פתחו http://localhost:8000
```

או פרסו ישירות ל-GitHub Pages / Netlify / Vercel — התיקייה כמות שהיא.
(Service Worker פעיל רק תחת HTTPS או localhost.)

## 🎧 הערה על Binaural Beats

יצירות המסומנות 🎧 מנגנות תדר שונה במעט בכל אוזן; המוח שומע את ההפרש ומסתנכרן
אליו. **חובה אוזניות סטריאו.** יצירות איזוכרוניות עובדות גם ברמקולים.

## ⚖️ גילוי נאות

המשמעויות המיוחסות לתדרים מגיעות ממסורות סאונד-הילינג ואינן טענות רפואיות
מוכחות (למעט גירוי גמא 40Hz הנחקר אקדמית). האפליקציה אינה תחליף לטיפול רפואי.
הסובלים מאפילפסיה — היוועצו ברופא לפני האזנה לפעימות קצביות.
