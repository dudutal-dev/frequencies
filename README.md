# ✦ RESONANCE — תדרים לאיזון הגוף והנשמה

אפליקציית פרימיום בסגנון Tidal להאזנה לתדרי ריפוי: **סולפג'יו, צ'אקרות, גלי מוח,
Binaural Beats, תיקון DNA ותדרי כדור הארץ** — עם מנוע סינתזה חי ומנדלה ויזואלית
שמגיבה לצליל בזמן אמת.

## ✨ מה מיוחד כאן

- **סאונד באיכות הגבוהה ביותר האפשרית** — כל יצירה מסונתזת בזמן אמת ב-Web Audio API
  בדיוק של אלפית הרץ. אין קבצי MP3, אין דחיסה, אין אובדן. שכבות הרמוניות
  ("קערה טיבטית"), LFO נשימה, ריוורב קתדרלה גנרטיבי ורעש ורוד אטמוספרי.
- **227 יצירות תדר** מסווגות ב-25 קטגוריות: מלודיות מרפאות, סולפג'יו (9 התדרים),
  7 הצ'אקרות, גלי מוח (דלתא 1Hz→גמא 40Hz), שינה, ריכוז ולמידה, רוגע ואיזון
  רגשי, אהבה וזוגיות, אירוטי עדין, אינטימלנד (לאוהבים), תיקון DNA, תדרים
  פלנטריים (האוקטבה הקוסמית של קוסטו), תדרי כדור הארץ, תהודת שומאן, קערות
  וגונגים, מנטרות ושירת גרון, שאמאני ופסיכדלי, פסיכדלי אורגני, דיפ האוס
  אורגני, טכנו וטראנס, מרחב פנימי, מדיטציה ואנרגיה.
- **מלודיות גנרטיביות** — רוב היצירות אינן צליל קבוע אלא מוזיקה חיה: מלחין
  אלגוריתמי מנגן פעמונים/קלימבה/נבל/הנדפאן/קריסטל/שירת-גרון/פסנתר-חשמלי/
  גיטרת-ניילון, או — במצב הזורם — חליל, קול אנושי ללא מילים ומיתרים, בכוונון טהור
  (Just Intonation) שבנוי על תדר הריפוי — הטוניקה היא תמיד התדר המרפא,
  והמנגינה לעולם לא חוזרת על עצמה.
- **ארבעה מצבי סינתזה** — תדר טהור · Binaural (🎧) · איזוכרוני (גם ברמקולים) ·
  מלודיה גנרטיבית.
- **84 מסעות מודרכים** (כ-64 שעות תוכן אוצר) — רצפים שמחליפים תדרים אוטומטית
  בקרוס-פייד: מסע 7 הצ'אקרות (מלא ואקספרס), צלילה אל השינה, לילה שלם (60 דק'),
  יקיצה מודרגת, פאוור-נאפ מושלם, SOS הרגעה מהירה, המסע הפלנטרי, הסולם
  הסולפג'י (עולה ויורד), מרתון בחינות (45 דק'), עבודה עמוקה, זרם היצירה,
  שערי השפע, פקיחת העין השלישית, עיבוד פרידה ואובדן, הקלה על כאב, ערב זוגי,
  ביטחון במה, חיבור לאדמה, הכרת תודה, דיטוקס אנרגטי, חלימה צלולה, מסע הלב
  הפתוח ועוד — עם פס התקדמות, דילוג בין שלבים ושליטה ממסך הנעילה.
  **בכל שלב בכל מסע מתנגנת שכבת מלודיה גנרטיבית** מעל התדר הפעיל: הביט
  הבינאורלי/האיזוכרוני ממשיך לעבוד על גלי המוח, והפעמונים מנגנים מעליו
  בכוונון טהור על אותו תדר יסוד.
- **פלייליסטים אישיים** — צרו רצפים משלכם (כפתור + בנגן), בחרו משך לכל תדר
  (3/5/10 דק'), והפלייליסט מתנגן ברצף אוטומטי.
- **ויזואליזציית מנדלה חיה** — Canvas ברזולוציית הפיקסלים הנטיבית של המסך
  (Retina/4K/8K), מוזנת מ-AnalyserNode ונצבעת בפלטת היצירה.
- **PWA מלאה** — התקנה על מסך הבית, עבודה אופליין, Media Session במסך הנעילה.
- **טיימר שינה** עם fade-out עדין של 10 שניות · מועדפים · אחרונים · חיפוש ·
  Auto-Save ל-localStorage.
- **עברית RTL** בעיצוב כהה יוקרתי: שחור עמוק, גרדיאנט זהב-סגול, טיפוגרפיית Heebo.

## 🚀 הרצה

אפליקציה סטטית ללא build וללא תלויות:

```bash
python3 -m http.server 8000
# פתחו http://localhost:8000
```

או פרסו ישירות ל-GitHub Pages / Netlify / Vercel — התיקייה כמות שהיא.
(Service Worker פעיל רק תחת HTTPS או localhost.)
